Newton's Three Laws

1st (inertia): an object keeps its state of motion unless a net force acts on it.

2nd: the net force equals mass times acceleration.

ΣF = m·a

3rd: forces come in pairs: if A pushes B with F, B pushes A with −F.

Common forces

Weight W = m·g (g = 9.8 m/s²)
Kinetic friction fk = μk·N
Static friction fs ≤ μs·N

Normal force N is perpendicular to the surface. Tension T pulls along a rope. Neither is automatically equal to mg, so always check with ΣF.

Inclined plane

Tilt your axes: x along the slope, y perpendicular to it.

W∥ = mg sinθ W⊥ = mg cosθ
N = mg cosθ
a = g(sinθ − μ cosθ) (sliding down)

It slides only if tanθ > μs.

Mechanical equilibrium

An object is in equilibrium when it has no linear and no angular acceleration.

ΣFx = 0 ΣFy = 0 Στ = 0
Torque τ = F · d⊥ (force × perpendicular lever arm)

Static equilibrium: at rest. Dynamic equilibrium: constant velocity.

Cables at angles

A sign hangs from two cables at angles α and β above the horizontal:

T₁cosα = T₂cosβ
T₁sinα + T₂sinβ = W
T₁ = W cosβ / sin(α+β)
T₂ = W cosα / sin(α+β)

Problem-solving recipe

  1. Sketch the situation; pick the object(s).
  2. Draw a free-body diagram: every force on the object.
  3. Choose axes (tilt them for slopes).
  4. Write ΣFx and ΣFy (and Στ for rotation).
  5. Solve, then sanity-check units and signs.
